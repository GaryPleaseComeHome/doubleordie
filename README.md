# Double or Die

A responsive football confidence-pool web app.

## Features

- Pick every weekly matchup against the spread
- Assign each confidence value exactly once
- Double one game for twice the reward or penalty
- Leaderboard, weekly matrices, player comparisons, and historical champions
- Local player profiles, saved pick cards, and light/dark themes
- Responsive layouts tested at desktop, tablet, and 320–390 px mobile widths

## Hosting

The site is deployed automatically to GitHub Pages from the `main` branch through `.github/workflows/deploy-pages.yml`.

> Player profiles and saved picks use browser-local storage. This static deployment does not provide server accounts or cross-device synchronization.
